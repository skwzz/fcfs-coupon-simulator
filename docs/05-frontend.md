# 05. 프론트엔드 설계

## 1. 스택

| 용도 | 선택 |
|---|---|
| 빌드 | Vite + React 18 + TypeScript |
| 서버 상태 | TanStack Query (REST) |
| 실시간 상태 | `EventSource`(SSE) + Zustand 스토어 |
| 차트 | Recharts (시계열 TPS, 지연시간) |
| 사용자 그리드 | `<canvas>`로 직접 그림 (DOM 수천 개는 느림) |
| UI | Tailwind CSS + shadcn/ui |

### 2.1 사용자 그리드
- 셀 하나가 가상 사용자 한 명이고, 상태에 따라 색이 바뀝니다. 대기 중인 셀은 순번이 앞일수록 진하게 표시합니다.
- 셀에 마우스를 올리면 툴팁(`user #3214 · WAITING · 순번 812`), 클릭하면 **사용자 타임라인 드로어**가 열립니다.
  ```
  user #3214
  0ms     REQUESTING
  4ms     WAITING   순번 3,214 (예상 16초)
  1.2s    WAITING   순번 2,980
  ...
  15.8s   ADMITTED  토큰 발급
  15.83s  SOLD_OUT  (응답 22ms)
  ```
- 렌더링: SSE `users` 변경분을 스토어의 `Uint8Array(status)`에 반영하고, `requestAnimationFrame`에서 바뀐 셀만 다시 그립니다.

### 2.2 "가상 사용자 한 명 들여다보기" 미니 폰 뷰 (선택)
그리드에서 사용자 3~4명을 고정(pin)하면, 오른쪽에 **휴대폰 모양 카드**로 그 사용자가 실제로 볼 화면을 그대로 보여줍니다.
대기열 팝업, 순번 감소 애니메이션, 결과 토스트를 사용자 시점으로 재현합니다.

## 3. "직접 참여" 모드

시뮬레이션(예: 가상 사용자 1만 명, 대기열 ON)을 돌린 상태에서 **브라우저 사용자 본인이** 실제 API로 참여합니다.

1. [쿠폰 받기] 클릭 → `POST /queue`
2. **대기열 모달**
   ```
   ┌──────────────────────────────┐
   │   🎟  접속 대기 중입니다       │
   │                              │
   │   내 앞에 3,214명            │
   │   ████████░░░░░░  예상 16초  │
   │                              │
   │   뒤에 4,880명이 대기 중      │
   │   새로고침하면 순번이 뒤로     │
   │   밀립니다.                   │
   │              [대기 취소]     │
   └──────────────────────────────┘
   ```
3. `queue/me/stream`(SSE)으로 순번 갱신 → `ADMITTED`가 오면 자동으로 발급 호출
4. 결과 화면: 🎉 발급 성공 / 😢 매진 / 이미 받음

같은 모달 컴포넌트를 2.2의 미니 폰 뷰에서도 재사용합니다.

## 5. 디렉터리 구조

```
frontend/src/
├── api/            # REST 클라이언트, SSE 훅 (useSimulationStream, useQueueStream)
├── stores/         # simulationStore (Zustand): tick 히스토리, 사용자 상태 배열
├── features/
│   ├── simulation/ # 설정 패널, KPI 카드, 차트
│   ├── user-grid/  # canvas 그리드, 타임라인 드로어, 미니 폰 뷰
│   ├── live-join/  # 직접 참여 모드, QueueModal
│   └── history/    # 실행 기록, 비교
└── components/     # 공통 UI
```
